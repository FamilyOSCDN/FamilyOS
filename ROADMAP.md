# FamilyOS Roadmap

The canonical FamilyOS roadmap is maintained at:

`docs/00-foundation/Roadmap.md`

This root-level file exists only as a repository entry point.

Canonical milestone, implementation, validation, and closure status must
be derived from the authoritative FamilyOS Foundation, Engineering
Constitution, ENG standards, ADR, RFC, SPEC, EPIC, testing, quality, and
release control documents.

Do not maintain an independent roadmap state in this file.
