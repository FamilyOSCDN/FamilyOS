# RFC-0003 — Plugin Discovery & Distribution

# 21 — Open Questions

The following topics require future decisions.

## Plugin Security Model

Questions:

- Should all plugins require signatures?
- How are publishers trusted?
- Should permissions exist?

## Repository Federation

Questions:

- How are multiple repositories prioritized?
- How are conflicts resolved?

## Plugin Isolation

Questions:

- Is runtime sandboxing required?
- What permissions should plugins have?

## Marketplace Integration

Questions:

- Should FamilyOS provide an official marketplace?
- How should publication work?

These questions are intentionally deferred.
